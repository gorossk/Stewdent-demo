# Stewdent 体験デモ

[体験デモを開く](https://gorossk.github.io/Stewdent-demo/)

「教える → 生徒AIがテスト → ふりかえって教え直す」を試す学習アプリです。

1. 「生徒AIに教えてみる」→「例を入れて試す」。テーマ・説明・キーワードだけで開始できます。
2. 生徒AI「レモン」が、教わった説明を使ってテストに答えます。
3. 説明を見つけられなかったキーワードを見て、もう一度教えます。テストを終えると10 XP、30 XPごとにレベルアップします。同じ結果を開き直しても重複加算しません。

先生は説明・生徒AIのテスト・根拠の引用を読み、所見を履歴に残せます。本人向けのチェック、全問の教師レビュー後の結果公開、チューターの指導記録も使えます。同じタブで役割を切り替えて試してください。

すべて架空データです。入力はタブ内メモリだけに保持し、再読み込みで消えます。実際の氏名や学校情報を入力しないでください。

**AI・テストの制限:** デモの対話は固定質問、AIの答案は説明文のキーワード照合と引用です。意味理解・知識の正確さの自動採点ではありません。AIが答えた数を本人の理解度・成績とは扱いません。OpenAI APIを呼ばず、トークン消費・API課金は発生しません。実認証・永続DBには接続しません。役割切替は本物の認証/RLSではありません。実試験や学校の評定には使えません。音声入力や他ユーザーとの対戦は未対応です。

このリポジトリは配信ファイルとブラウザ検証だけです。原本のプランシート・動画・実校の情報・秘密・SQL・非公開の模範回答は含みません。日本語の丸いフォントは自己配信しています。SIL Open Font Licenseは[FONT-LICENSE.txt](./FONT-LICENSE.txt)を参照してください。

GitHub Pagesはmain / (root)。[公開URLの操作検証](https://github.com/gorossk/Stewdent-demo/actions/workflows/verify-demo.yml)で、教える/AIテスト/ふりかえり/教え直し/育成/教師所見/本人Check/レビュー/公開/チューター、375px、フォント、API・外部要求0を確認します。スクリーンショットとresult.jsonはActions artifactです。

URLを知る人は閲覧できます。CSP connect-src noneとnoindexを設定していますが、noindexは閲覧制限ではありません。

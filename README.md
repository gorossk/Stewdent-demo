# Stewdent 会話とテストの体験デモ

[体験デモを開く](https://gorossk.github.io/Stewdent-demo/)

生徒AI「レモン」と会話して教え、テストを受けてもらい、結果を見て同じ会話で教え直すアプリです。

1. 「生徒AIに教えてみる」から会話へ。テーマの例か「会話例を入力する」を使い、最初のメッセージを送ります。
2. レモンの質問に答えながら教えます。まとめの提出や会話の終了は不要です。
3. 「レモンにテストを受けてもらう」。その時点の会話だけで答えます。スマホは「AIのテスト」タブから開きます。
4. 「この会話で教え直す」で補足し、もう一度テスト。第1回/第2回を切り替えて比較でき、後の説明で過去の答案は変わりません。再表示でXPは増えません。

先生は、会話・各回のAIテスト・元の発言を読み、所見を履歴に残せます。本人用Checkの固定設問/提出/全問教師レビュー/結果公開、チューター記録も維持しています。同じタブで役割を切り替えて試してください。

すべて架空データです。入力はタブ内メモリだけに保持し、再読み込みで消えます。実名や学校情報は入力しないでください。

**デモの制限:** 会話は文脈に応じたルール、テストはテーマ別の独自問題と説明条件の照合・引用です。本物のAIの意味理解や正誤の全面的な採点ではありません。江戸幕府の始まりの誤りを確認資料と比べる例もありますが、本人の理解度・正式評定は確定しません。OpenAI APIへの通信/トークン消費/課金なし。実認証/永続DBには接続せず、役割切替は本物のRLSではありません。教師が作るAI専用問題バンク、音声、対戦/着せ替えは未対応です。

このrepoには静的配信物と検証のみを置きます。原本資料/実校情報/秘密/SQL/非公開Check正答を含みません。丸い日本語フォントを自己配信し、[OFL](./FONT-LICENSE.txt)を同梱。CSP connect-src none、noindexを設定していますが、URLを知る人は閲覧できます。

GitHub Pages: main / (root)。[実URLのブラウザ検証](https://github.com/gorossk/Stewdent-demo/actions/workflows/verify-demo.yml)は会話/複数回テスト/過去結果/同じ会話での補足/教師所見/本人Check/レビュー/公開/チューター、375px、フォント、API・外部要求0を確認し、画像とresult.jsonをartifactに保存します。
